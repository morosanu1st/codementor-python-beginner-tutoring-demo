# Codementor Python Beginner Tutoring Demo

Tiny exercises and a clear path for **Python beginner** 1:1 tutoring. Practice files live under `exercises/`; worked solutions under `answers/` (try before peeking).

## What’s in this repo

| Path | Topic |
|------|--------|
| `exercises/01_hello.py` | Print / first program |
| `exercises/02_variables.py` | Variables & types |
| `exercises/03_lists_dicts.py` | Lists and dictionaries |
| `exercises/04_mini_script.py` | Small end-to-end script |
| `answers/` | Reference solutions (clearly marked) |

## 4-week beginner path

| Week | Focus | Session goals |
|------|--------|----------------|
| 1 | Syntax & variables | Run scripts, print, numbers/strings, simple input |
| 2 | Collections | Lists, dicts, loops, `if` |
| 3 | Functions & files | `def`, return values, read a text file |
| 4 | Mini project | Combine skills into one short useful script |

Each week: short demo → guided exercise → you redo a variant alone → we review mistakes together.

## How 1:1 sessions work

1. **Warm-up** (a few minutes) — what you tried since last time.
2. **Teach + type together** — concepts on a shared editor.
3. **You drive** — I coach, you write the next function.
4. **Recap** — 2–3 bullet “remember this” notes + a tiny homework.

First **15 minutes free** on Codementor to check your setup (Python version, editor) and pick the right starting week.

## How to use the exercises
